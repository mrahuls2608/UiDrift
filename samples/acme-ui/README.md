# acme-ui (sample)

A small, deliberately inconsistent front-end used to demo UIDrift's **source-code audit**.
Four teams styled it four ways: SCSS, Tailwind, styled-components and inline styles.

```bash
npm run analyze -- samples/acme-ui        # from the repository root, no LLM needed
```

To try the upload flow in the app, use [`samples/acme-ui.zip`](../acme-ui.zip): **New audit → Source code → Upload → Choose ZIP**.
